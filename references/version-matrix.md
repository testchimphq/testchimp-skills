# CLI and runtime version notes

_Moved from the `compatibility` frontmatter field of SKILL.md (v1.0.57) so that field stays short and YAML-safe. Only change: em dashes replaced with colons._

**MCP API 2.0.0 / CLI 2.0.0:** skill **2.0.0** requires TestChimp MCP API **2.0.0** (`metadata.required_mcp_version`) and **`@testchimp/cli` ≥ 2.0.0** (`metadata.required_cli_version`, 85 tools). Hosted / plugin MCP at `https://mcp.testchimp.io/mcp` must be on 2.0.0. Tool names, `list-issues` filters (`statuses` / `severities` / `assignees` / `ordinalIds`), `upsert-release` (`gitCommitSha`, `priorReleaseVersion`), `manage-test-run` (no `action`; `commitRange` FIND\|LINK), and scan `scanId` match [`cli.md`](./cli.md) and Aware OpenAPI 2.0.0. **`get-eaas-config` is kept unchanged** as the connectivity / first-run / auth-gate check (empty `{}` is OK; do not use `ephemeral-environment action=CONFIG`).

**`ask-about-testchimp` / `ask-testchimp-question`:** last-resort product Q&A. Answer from this skill pack first. Limits: ≤ **2,000** characters per question; **20** questions per project per hour. See [`cli.md`](./cli.md) § `ask-about-testchimp` and [`agent-quick-answers.md`](./agent-quick-answers.md).

Requires Node.js; web projects need @playwright/test and playwright >= 1.59.0 (see Preamble checks #6). Mobile projects need mobilewright + @mobilewright/test (see references/mobilewright-smarttests.md). TrueCoverage RUM clients: **#7** (`@testchimp/rum-js`, SwiftPM **testchimp-rum-ios**, JitPack **testchimp-rum-android**). Playwright plugin: **#8** (`@testchimp/playwright`: bump on create-tests / run-qa / upkeep). **`TESTCHIMP_API_KEY`:** Preamble checks **#4** (runner process, not only MCP/IDE). Network access for TestChimp APIs when using MCP, CLI, or AI steps. CLI ≥ **0.1.28** for API operation coverage tools (`get-api-operations`), semantic nearby tools, workflow/policy tools, `get-execution-history --test-id`, and `get-test-scenarios --external-ids`. CLI ≥ **0.1.29** for `get-org-capabilities` (org capability soft-gating for TrueCoverage / API contract coverage). CLI ≥ **0.1.30** for `get-spec-lifecycle-details` (scenario `verification_strategy` before authoring SmartTests) and skill/CLI version on `report-agent-action` / `agentTraceability`. CLI ≥ **0.1.32** for `get-plans-support-file` (platform-first read of a named workflow plan). CLI ≥ **0.1.33** for `mark-tests-for-review` (report existing-test fixes after fix-test-execution). CLI ≥ **0.1.66** for `testchimp chimphands refresh-git-auth` (remint GitHub App installation token on long-lived ChimpHands jobs). CLI ≥ **0.1.80** documents API-operation daily observability summaries for coverage/performance prioritization. CLI ≥ **0.1.81** for `get-meeting-transcript` (Meeting Bots cloud transcript by meeting id). CLI ≥ **0.1.82** for `list-meetings` (`meetingSetId`) (meeting-set context from the Meetings page) and `get-meeting-transcript --summary-only`. CLI ≥ **0.1.83** for `list-meetings` / `list-meetings` (`includeFilterOptions=true`) (search team-wide meetings by date range, labels, participants, domains, full text). CLI ≥ **0.1.85** for QA-bot mode (`get-my-tasks`, `get-qa-posture`, `list-tests-awaiting-verification`, `get-bot-compat`, `get-bot-profile`, `register-bot-profile`, `ack-bot-events`, `testchimp bot …`, OAuth bearer + `bot-id` header, remote `mcp --http`, `testchimp workspace map|get` for the per-user local folder mapping, `testchimp bot connect|disconnect` for Studio-free AgentWatch credentials). CLI ≥ **0.1.86** for AgentWatch pairing without a browser (`testchimp bot connect --pair` / `--finish-pair`, `approve-agentwatch-pairing`). CLI ≥ **0.1.87** for `send-feedback` (agent feedback / bug reports / user struggles to the TestChimp team). CLI ≥ **0.1.88** for per-bot project binding (`get-bot-credentials`, `testchimp bot save-binding|remove-binding|exec`, global `--bot <botId>`, and `projectApiKey` / `botId` arguments on every remote MCP tool). CLI ≥ **0.1.90** for remote MCP per-project URLs (`https://mcp.testchimp.io/mcp?projectId=<id>`), `get-project-credentials` with backend/ingress hosts, and the CLI's `.testchimp/mcp.json` key fallback. CLI ≥ **0.1.91** for `invite-team-members` (invite teammates by email; OAuth org-admin sessions only, last step of project init), `update-workflow-execution-assignees` (set a workflow execution's assignee / CC; OAuth user or `--bot`), and `get-workflow-executions` `assignedToMeOnly`. CLI ≥ **0.1.93** for `save-workspace-creds` (stdio MCP writes `.testchimp/mcp.json` without the key on the wire). Hosted / plugin MCP still saves the runner key via `get-project-credentials` plus a file-write tool.
