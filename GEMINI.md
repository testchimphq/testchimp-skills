# TestChimp

TestChimp is the QA platform for coding agents. The `testchimp` MCP server exposes consolidated QA coverage signals (scenario coverage, API contract coverage, TrueCoverage from real user sessions, observability), in-repo test plans, test verification state and release readiness.

When the user asks to test a change, find coverage gaps, write or fix E2E or API tests, trim a large suite, or check whether a release is ready, load `SKILL.md` at the extension root and follow its routing table. Start with `get-qa-posture` for an overview and `get-requirement-coverage` for gaps.
